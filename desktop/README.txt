유튜브 자막 (포터블)
====================

설치 없이 쓰는 유튜브 자막 추출 프로그램이에요.
- 라이브 방송: 지금까지 진행된 부분의 자막을 만들어요.
  같은 방송을 다시 요청하면 지난번 이후 새로 방송된 부분만 인식해요.
- 종료된 영상: 유튜브 자막이 있으면 그대로 가져오고, 없으면 새로 만들어요.

실행 방법
---------
1. 압축을 모두 풀어요. (압축 파일 안에서 바로 실행하면 안 돼요)
2. YouTubeSubtitle.exe 를 더블클릭해요.
3. 브라우저에 자막 화면이 열려요. 유튜브 주소를 붙여넣고 버튼을 누르세요.
4. 결과는 복사하거나 TXT / SRT 파일로 저장할 수 있어요.

끄는 방법: 작업 표시줄 오른쪽(시계 옆) 트레이의 재생 버튼 모양 아이콘을
오른쪽 클릭 → 종료. (브라우저 탭만 닫으면 프로그램은 계속 켜져 있어요)
화면을 다시 열기: 트레이 아이콘 더블클릭, 또는 YouTubeSubtitle.exe 다시 실행.

처음 실행할 때
--------------
- "Windows의 PC 보호" 창이 뜨면: [추가 정보] → [실행]을 누르세요.
  (서명되지 않은 개인 프로그램이라 나오는 경고예요)
- 방화벽 허용 창이 뜨면 허용하지 않아도 돼요. 이 PC 안에서만 쓰는 프로그램이에요.

속도
----
음성 인식은 이 PC의 CPU로 해요. 일반 노트북에서 방송 1시간을 인식하는 데
약 15분 걸려요. 인식된 문장은 처리되는 대로 화면에 바로 나와요.

더 빠르게 하려면 (선택): Groq API 키(https://console.groq.com/keys)가 있으면
이 폴더에 groq-key.txt 파일을 만들어 키 한 줄을 넣고 프로그램을 다시 켜세요.
1시간 분량을 1~2분 안에 처리해요.

폴더 구성
---------
YouTubeSubtitle.exe   실행 파일
app\                  프로그램
runtime\              실행에 필요한 도구들 (Node, Python, 음성 인식 모델 등)
data\                 저장된 라이브 자막과 로그 (처음 실행하면 생겨요)

필요한 것: Windows 10/11 64비트, 인터넷 연결 (유튜브 접속용)
